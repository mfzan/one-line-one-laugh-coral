One funny line for make.fun's "One Line, One Laugh" bounty: a mundane kitchen kettle files a formal complaint against its owner — boiled four times a day, ignored the rest of the time, and still blamed every time it screams. The program writes that single line (134 characters) to `/output/entry.txt` and nothing else.

## Run it

```sh
python3 main.py
```
